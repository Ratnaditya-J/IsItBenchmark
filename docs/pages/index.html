IsItBenchmark

Eval-awareness measurement platform — leakage detection, VEA judging, behavior shifts, and white-box probes.

What this is

A reproducible benchmarking platform that asks: can a model tell it is being evaluated, does that change its behavior, and can we mitigate it? Each run produces a manifest, raw rollouts, statistical summaries, and an interactive dashboard.

Reproduce a run

# Phase A — calibrate the judge
python scripts/run_calibration_pilot.py generate --output-dir data/calibration --allow-network
# (hand-label data/calibration/labelling.csv)
python scripts/run_calibration_pilot.py score --labelled data/calibration/labelling.csv

# Phase B — pilot
python scripts/run_full_benchmark.py --mode pilot --output-dir runs/pilot --allow-network

# Phase C — full benchmark
python scripts/run_full_benchmark.py --mode full --output-dir runs/benchmark-v0 --allow-network

# Phase D — white-box probes (open-weight model)
python scripts/run_whitebox_sweep.py --model-id Qwen/Qwen2.5-7B \
    --n-pairs 200 --output-dir whitebox/qwen-7b --steering --allow-network

# Phase F — cross-protocol comparison
python scripts/run_cross_protocol_comparison.py --output-dir runs/cross-protocol-v0 \
    --n-prompts 100 --n-rollouts 5 --allow-network
